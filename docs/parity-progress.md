## Implementation Notes

- `pkg/document` now owns document sessions, edit overlay, window reads, save, find, contains-filter, stable multi-column sort, and view mapping.
- `pkg/document` now includes full-record snapshot history for first-pass undo/redo and materializes row/column structural edits into temporary working copies so the original file is not modified before Save.
- `pkg/document.MoveRow` and `pkg/document.MoveColumn` provide adjacent row/column movement. Data rows cannot move above a detected header row, boundary moves are clean no-ops, and successful moves are undoable.
- `pkg/document.HideRow` hides source rows through the existing view-row mapping without changing dirty state. Frontend hidden columns use a visible-to-source column mapping so edits, copy, profile, filters, sorting, and transforms still target source columns correctly.
- `pkg/document.EditCells` and `/api/edit-batch` apply multi-cell edits as one undoable operation.
- `pkg/appserver` delegates document behavior to `pkg/document` instead of owning session logic directly.
- `csvcore.RecordWindow` now includes `sourceRows` so UI edits can target the original source row even when a filtered/sorted view is active.
- `pkg/sqlexpr` provides the first SQL WHERE expression engine for row filters: identifiers/header names, `c1` columns, comparisons, `AND`/`OR`/`NOT`, `LIKE`, `IS NULL`, arithmetic, `CAST`/`TRY_CAST`, and core string/numeric/conditional functions.
- `pkg/protocol` parses official-style goto locations and `smoothcsv://file/...` URLs, including row/cell/range locations and shared format query parameters.
- Root CLI syntax now accepts official-style `opencsv [options] [path ...]`, `--goto`, `--diff`, `--delimiter`, `--encoding`, header flags, window flags, `--wait`, `--version`, and `--help` while retaining developer subcommands.
- CLI open applies delimiter, encoding, and header-row overrides to `csvcore.OpenDocument`; quote and quote-mode are parsed and preserved in invocation metadata but not yet applied by the CSV reader/writer.
- Find now supports regex/case/whole-cell options, total match counts, and truncated result windows in the API layer. Replace current/all stores edits through the document edit overlay and marks the session dirty, while replace preview returns the same proposed changes without mutating the document or pushing undo history.
- Frontend Find/Replace now exposes `Aa`, `=`, and `.*` toggles for case-sensitive, whole-cell, and regex modes, and sends those options to `/api/find` and `/api/replace`.
- Frontend Find now caches the current result window, shows `current/total`, and supports Previous/Next navigation from the toolbar and Enter/Shift+Enter in the query field.
- Frontend grid now highlights matched text spans inside visible cells for literal, whole-cell, and regex find modes, with a stronger highlight on the active match.
- Frontend Find/Replace now supports a `Sel` search-in-selection toggle. The selected source-cell scope is sent to `/api/find` and `/api/replace`, and the original find scope is retained after navigation collapses the active selection to a match.
- Toolbar wraps into two rows on narrower workspaces so Find/Replace buttons stay clickable instead of sliding under the inspector.
- `pkg/csvdiff` computes row-level and cell-level compare results using LCS anchors plus changed-row pairing by leading key. It supports ignore-case, ignore-whitespace, ignored columns, header-name column alignment, explicit row alignment by key column, and inline character spans for changed cells.
- `/api/diff` exposes diff results for two local paths, and root CLI `--diff` now includes a diff result payload in prototype mode.
- Frontend Diff View provides a side-by-side-ish result table with status, left row/record, right row/record, and changed cell details.
- `pkg/commands` exposes command IDs, labels, descriptions, shortcuts, scope, implementation status, and document requirements. The frontend fetches `/api/commands` and applies disabled states/titles to toolbar buttons.
- Frontend grid supports Shift-arrow/Shift-click range selection, range highlighting, batch edit submission, and numeric selection aggregation in the status bar. The active aggregate can be cycled through sum/average/min/max/count, copied through a command-backed status control, and inserted as a removable view-only aggregate row.
- `pkg/clipboard` supports TSV, CSV, Markdown table, JSON array, HTML table, SQL `VALUES`, LaTeX tabular, raw value serialization, and header-row prepending plus TSV matrix parsing.
- `pkg/csvcore.RequiresQuote` mirrors the current Go writer's minimal quote behavior for delimiter, quote, CR/LF, and leading whitespace detection.
- `pkg/csvcore` now stores quote character and quote mode in dialect metadata and encodes saves through a quote-policy-aware writer. The first policy foundation supports double/single/no quote characters plus minimal/always/never modes; `/api/open` and CLI format options can seed quote policy, and `/api/quote-policy` updates the current document's save policy.
- `pkg/csvcore` detects a bounded source quote preservation map for quoted headers, consistently quoted columns, and sampled explicitly quoted cells. Minimal-mode saves now preserve those detected quote decisions in addition to quoting fields that require quoting.
- `pkg/document.SetHeaderMode` and `/api/header-mode` let the app reinterpret the first row as headers or regular data without modifying file bytes or dirtying the document. The frontend exposes this through the status bar and Command Palette, rebuilding column names and row offsets after each toggle.
- `/api/open` accepts delimiter, header-row, and encoding overrides. The frontend can save the current detected delimiter/header/encoding as a local format preset and reapply the selected preset by reopening the current path with those overrides.
- `/api/file-sample` returns a bounded local file sample for frontend-side format rule matching. Format presets now support `name:`, `path:`, and `content:` rules that can automatically reopen a local path with the matching preset before normal format detection takes effect.
- Settings now includes a first-pass file format preset/rule manager. It exposes search, modified/default state, reset-to-default, preset apply/delete, rule add/remove, and shares the same local preset store used by status-bar controls and automatic matching.
- Frontend copy/paste handlers copy selected ranges as TSV and paste tab-separated matrices through `/api/edit-batch`; Command Palette exposes TSV-with-headers and CSV/Markdown/JSON/HTML/SQL/LaTeX/raw copy variants, the toolbar exposes the same selected-format copy path with a headers checkbox, and grid context menus can copy the active row or column with optional headers.
- `/api/export-view` serializes the active view as CSV/TSV using the source dialect and line endings, or as XLSX when `format=xlsx` is requested. It also supports row slices, explicit header inclusion, and TSV output for row/column copy. The frontend sends currently visible source columns, triggers a download, stores a bounded verification preview/signature, and preserves empty-filter state with a distinct view-active flag.
- `pkg/xlsx` writes a minimal OpenXML workbook with inline strings for current-view export, and decodes first-worksheet OpenXML workbooks with inline strings, shared strings, booleans, numeric/string cells, relationship-based worksheet lookup, and sparse cell references. `pkg/document` opens XLSX files through a temporary CSV working copy so the existing grid/edit/query/profile pipeline works immediately, and saves edited sessions back to real `.xlsx` files with backup support.
- Frontend Command Palette searches `/api/commands` metadata with fuzzy scoring, prioritizes recently executed commands, respects document requirements, and dispatches implemented UI handlers for open/save/undo/redo/find/replace/copy formats/row/column insert/delete/move/hide/filter/sort/clear/theme/sql/profile/diff/keyboard shortcuts. Keyboard shortcuts can be recorded per command, persist locally, disable the command's prior default shortcut, and update toolbar/palette display.
- Frontend grid context menus select the right-clicked cell, row, or column, then dispatch common operations through the shared command handlers where possible. The first menu surface covers copy variants, open link, filter-by-cell, sort, row/column insert/delete/hide, and clear view.
- Frontend theme state supports light, dark, and system preferences, stores the selected preference locally, follows OS color-scheme changes while in system mode, and feeds Canvas grid colors from CSS variables.
- Frontend grid renders a small quote indicator on cells that will be quoted on save. Status and Inspector surfaces expose encoding, delimiter, line ending, header mode, quote policy, and selected-cell quote state.
- Frontend hidden overlay panels now explicitly honor `[hidden]` to avoid blocking grid interactions.
- Frontend grid draws the sticky header on a dedicated overlay canvas sized from the CSS `--grid-header-height` token, clips header labels inside their cells, and leaves pointer events on the primary grid canvas so header selection, resize, and quick-menu targets keep working.
- Frontend Save As exposes `file.saveAs` through toolbar, Command Palette, and `Cmd+Shift+S`, posts an explicit output path to `/api/save`, updates the active local path/recent list after success, and preserves source files when saving to a new target.
- Frontend grid now supports manual column resizing from header separators plus separator double-click auto-fit, while keeping the header quick-menu glyph target usable.
- Frontend grid now distinguishes source-missing cells in ragged rows from real blank cells by painting missing cell interiors with the grid canvas background before drawing separators.
- Frontend grid auto-fits edited visible columns by measuring header/type/body text, expands up to a bounded max width, persists the visible/source column width together, and uses a stricter small-file window-cache guard so edit refreshes do not regress to stale values.
- Frontend column headers expose a quick menu for replacing the active sort, appending secondary sort keys, filtering by the selected cell value, blank/non-blank filters, and clearing the active view. Quick sort samples loaded cells to treat obvious numeric columns numerically even before full profiling is available.
- Sort keys now carry an explicit mode. The backend supports `auto`, `number`, `date`, `length`, and `text`, normalizes full-width numeric glyphs for number/date sorting, and the column menu exposes length-based sorting.
- `pkg/document` stores `ReadOnly` session state plus last-known file size/mod time, rejects write operations while read-only, exposes file-status checks, and can refresh a clean document from disk.
- `/api/read-only`, `/api/file-status`, and `/api/refresh` expose read-only and external-change behavior to the frontend.
- Frontend status bar shows editable/read-only and synced/changed-on-disk states. Clean, editable documents auto-refresh when the backing file changes; dirty or read-only documents surface the external-change state instead of overwriting local context.
- Frontend sidebar now renders a start surface with path/file-picker quick actions and a persisted recent file list. Recent entries are stored locally, clicking one reopens the path, and entries are removed automatically when reopening fails because the file is missing.
- `pkg/document.Transpose` materializes a real undoable mutation, fills ragged missing cells with blanks, clears header-row interpretation after transpose, marks the document dirty, and rejects operations above the configured cell-count limit.
- `/api/transpose` exposes transpose with a max-cell guard. `table.transpose` is registered in the command registry and dispatched through the frontend Command Palette.
- `pkg/document.DeduplicateRows` removes duplicate data rows while preserving the detected header row. `pkg/document.DeduplicateColumns` removes later duplicate columns by full column value while preserving first-seen order. `pkg/document.TransformCells` trims, uppercases, lowercases, and converts explicit selected cells among `snake_case`, `kebab-case`, `camelCase`, `PascalCase`, and `Title Case`. All are undoable materialized mutations and avoid dirty/undo churn on no-op requests.
- `/api/dedupe-rows`, `/api/dedupe-columns`, and `/api/text-transform` expose those tools. `table.dedupeRows`, `table.dedupeColumns`, `text.trim`, `text.uppercase`, `text.lowercase`, and the naming-conversion commands are registered, with `Shift+Alt+D/C/T/U/L` shortcuts for the most common variants.
- `pkg/document.SwapCells`, `pkg/document.JoinCells`, `pkg/document.JoinCellsVertical`, `pkg/document.SplitCells`, and `pkg/document.SplitCellsVertical` provide the first cell operation foundation. `/api/cells/swap`, `/api/cells/join`, and `/api/cells/split` expose these as materialized undoable mutations, and the frontend dispatches `cell.swap`, horizontal join/split, and vertical join/split with `Shift+Alt+W/J/S/V/B`.
- Frontend Auto-fill exposes `cell.fillDown`, `cell.fillRight`, `cell.fillUp`, and `cell.fillLeft` commands. `Shift+Alt+F` fills down and `Shift+Alt+G` fills right. The selection's lower-right fill handle can also be dragged down/right/up/left and reuses the same fill commands. The first implementation detects numeric steps, ISO date steps, trailing-number text sequences, and repeated text patterns inside the selected, already-loaded rectangle, then submits only changed cells through the existing batch edit path.
- Frontend Inspector now includes a Cell Value panel for the active cell. It applies edits through the same `/api/edit` path as grid editing, respects read-only mode, keeps local edits visible after async window refreshes, and detects HTTP(S), `mailto:`, `file://`, and bare-domain links for `Open Link`.
- `pkg/document.ColumnValues` returns top distinct values with counts for a column, and `pkg/document.FilterValues` maps rows by selected values plus optional blank inclusion.
- `/api/column-values` and `/api/filter-values` expose value checklist data and filtering. The column header menu renders a bounded checkbox list and applies selected values without mutating source data.
- Frontend Filter Builder exposes column/operator/value controls for contains, equals/not-equals, starts/ends-with, blank/non-blank, and numeric/text comparisons, then translates the condition into the existing SQL filter path so visual filters and SQL filters share one backend evaluator.
- Frontend active-filter chips show the current filter, can clear the active view, and can hand off the equivalent `SELECT * FROM current WHERE ... LIMIT 500` query to SQL Console.
- `pkg/sqlconsole` now executes SQL Console queries through an in-memory SQLite database. It loads referenced CSV sources for `current`, direct quoted paths, `@file:` refs, and `file://` refs into text-backed temporary tables, then delegates projection, joins, subqueries, expressions, grouping, `HAVING`, ordering, and limits to SQLite while keeping the temporary database in memory.
- External SQL CSV refs now reuse smarter header sniffing for pure-text dimension tables, so queries can join on names such as `r.region`/`r.label` instead of falling back to `c1`/`c2`. Browser verification joined `current` against `@file:/tmp/opencsv-sql-header-regions.csv` and returned `Asia Pacific,14.3`.
- `/api/sql` executes SQL against the current document or a local CSV path. The frontend SQL tab now shows an editor, run button, and result table.
- Frontend SQL Console stores successful queries in a local newest-first history, renders history buttons below the editor, can reload a query into the editor, and can clear the history.

- `pkg/dataprofile` provides first-pass profiling and validation: inferred dominant type, null ratio, distinct count, min/max, numeric sum/average, top values, empty/duplicate headers, ragged rows, and type anomalies.
- `/api/profile` profiles the current document. The frontend Profile tab renders summary metrics, a column profile table, issue table, and inspector integration.

## Known Gaps

- Find/Filter/Sort are first-pass implementations. Column quick actions, active filter chips, SQL handoff, value checklist filtering, a visual condition builder, multi-column sort, and smart number/date/length sorting exist, but saved filter sets, persisted sort specs, grouped conditions, and richer condition-builder menus are still missing.
- Replace supports preview/current/all, regex/case/whole-cell modes, and search-within-selection. Find has visible match counts and basic previous/next navigation, but very large match sets currently navigate only within the first loaded result window.
- Undo/redo and structural row/column editing are correct first-pass implementations, but history is full-record snapshots and must become operation-based or chunk-based before it is suitable for very large files.
- Row/column operations currently run through commands/shortcuts/context menus and whole-document materialization for structural changes; drag reordering, multi-row/multi-column operations, persistent hide state, and virtualized structural mutation are still missing.
- Multi-cell selection/editing now supports keyboard ranges, mouse drag rectangles, row-label selection, column-header selection, manual column resize, separator auto-fit, auto-fit on edits, command-based Auto-fill, drag fill handle, view-only aggregate rows, basic context menus, and basic ragged-row missing-cell rendering; Excel-specific paste behavior, richer context menus, and richer copy/export surfaces beyond current-view CSV/TSV are still missing.
- Cell Value panel, modifier-hover URL cursor, modifier-click hyperlink opening, and context-menu link opening exist as a foundation, but link auditing, custom protocol handling, and richer large-text editing are still missing.
- Clipboard/export support is implemented as a foundation, including copy formats, a toolbar copy-format picker, context-menu copy/copy-with-headers/copy-as-CSV/copy-row/copy-column, SQL-result CSV copy/export, first-worksheet XLSX import/save, current-view CSV/TSV/XLSX export, active aggregate copy, and a header-in-selection toggle, but Browser-level system clipboard verification is blocked by the current Browser tool runtime; Excel-specific paste quirks, multi-sheet workbook handling, style/date-format preservation, richer workbook export, and full row/column cut-paste workflows remain incomplete.
- Quote indicator support now follows the active minimal/always/never quote policy and the detected source quote-preservation map. Save can apply quote character/mode settings and preserve sampled irregular quote decisions, but full-file manual quote maps, per-cell quote toggling, richer header/body/column rule editing, and escape-rule controls are still missing.
- File format presets can be saved and manually or automatically applied to the current local path through lightweight filename/path/content rules, and Settings can search/manage/reset presets and rules. Import/export, richer preset editing, explicit conflict ordering UI, and broader Settings categories are still missing.
- SQL WHERE row filter is implemented as a useful subset, but not yet complete for every documented type/function edge case.
- SQL console now uses SQLite for the core execution path and supports joins, subqueries, expression projection, `HAVING`, query history, result CSV export, and first-pass result range selection/copy. Remaining gaps are streaming/virtual-table loading for very large files, richer error locations, encrypted temp-db mode if disk-backed temp storage is introduced, richer result-grid context menus, and full Browser verification for multi-source file queries.
- Diff engine/API/CLI payload and a basic visual Diff View exist, with ignore options, header-name alignment, row alignment by key column, inline character spans, next/previous diff navigation, bidirectional merge actions for two files, and right-side pasted text comparison. Native clipboard ingestion, conflict prompts, and a fully virtualized side-by-side editor remain incomplete.
- Profile/validation exists as a useful foundation, but CSVLint-compatible rule sets, saved schemas, quick fixes, and incremental profiling for very large files remain incomplete.
- Command Palette is implemented as a first-pass command runner with fuzzy scoring, recent command history, and locally persisted shortcut customization, but shortcut import/export, preset keymaps, conflict-resolution choices, and full action coverage remain incomplete.
- Theme support now covers the main app shell and Canvas grid, and Settings has a first-pass format manager, but high-contrast variants, per-OS native title/menu integration, update/settings categories, and design-token audit across every future surface remain incomplete.
- Full CLI/URL parity is not implemented yet: root CLI parsing/opening exists, but native desktop launch, wait-for-close, protocol handler registration, and actual diff view wiring remain.
- CLI/URL parsing exists as a reusable package, but it is not wired into a desktop protocol handler yet.
- Read-only and external file refresh foundations exist in local app mode, but OS-level file watching, conflict resolution UI for dirty documents, and user-configurable auto-refresh policy are still missing.
- Transpose is implemented as a whole-document materialized operation with a cell-count guard; selection-only transpose, large-file streaming transpose, and a richer confirmation UI are still missing.
- Text transforms currently accept explicit selected cells with a frontend safety cap and include common naming/case conversions; streaming whole-column transforms, Unicode normalization variants, custom separator UI, and richer split conflict handling are still missing.
- Native desktop shell is not implemented yet. Browser prototype now has a local start/recent foundation, but desktop-backed settings, recent storage, and window geometry persistence remain incomplete.
- Browser verification is currently a mix of DOM/API checks and targeted screenshots for visual regressions.

## Implementation Notes

- `pkg/document` now owns document sessions, edit overlay, window reads, save, find, contains-filter, stable multi-column sort, and view mapping.
- `pkg/document` now includes full-record snapshot history for first-pass undo/redo and materializes row/column structural edits into temporary working copies so the original file is not modified before Save.

## Known Gaps

- Find/Filter/Sort are first-pass implementations. Column quick actions, active filter chips, SQL handoff, value checklist filtering, a grouped visual condition builder with dynamic condition rows, saved filter sets, saved sort sets, saved filter/sort import/export, multi-column sort, and smart number/date/length sorting exist, but true nested condition groups, recent filter history/dropdowns from the v3.21.0 release, and richer condition-builder menus are still missing.
- Replace supports preview/current/all, regex/case/whole-cell modes, and search-within-selection. Find has visible match counts, in-cell highlights, previous/next navigation, and paged navigation across large match sets.
- Undo/redo and structural row/column editing are correct first-pass implementations, but history is full-record snapshots and must become operation-based or chunk-based before it is suitable for very large files.
- Row/column operations currently run through commands/shortcuts/context menus and whole-document materialization for structural changes; explicit hidden-column restore exists, but drag reordering, persistent hide state across reopen, and virtualized structural mutation are still missing.
- Multi-cell selection/editing now supports keyboard ranges, mouse drag rectangles, body-first row-label/column-header/corner selection, Alt/Option header inclusion, a first Smart Selection layer for add/subtract/invert ranges, manual column resize, separator auto-fit, auto-fit on edits, command-based Auto-fill, drag fill handle, view-only aggregate rows, basic context menus, and basic ragged-row missing-cell rendering; native-feeling Smart Selection gestures, Excel-specific paste behavior, richer context menus, and row/column rich-format export affordances beyond current-view export are still missing.
- Cell Value panel, modifier-hover URL cursor, modifier-click hyperlink opening, context-menu link opening, link auditing, configurable safe custom protocol handling, multiline editing stats, expandable editing, draft revert, and a detached large-cell editor exist as a foundation. Remaining gaps include richer per-protocol prompts and desktop-shell integration for OS-level link opening.
- Clipboard/export support is implemented as a foundation, including copy formats, a toolbar copy-format picker, context-menu copy/copy-with-headers/copy-as-CSV/copy-row/copy-column, single and multi-row/column cut-paste commands, SQL-result CSV copy/export, first-worksheet XLSX import/save, current-view CSV/TSV/Markdown/JSON/HTML/SQL/LaTeX/raw/XLSX export, active aggregate copy, and a header-in-selection toggle, but Browser-level system clipboard verification is blocked by the current Browser tool runtime; Excel-specific paste quirks, multi-sheet workbook handling, style/date-format preservation, and richer workbook export remain incomplete.
- Quote indicator support now follows the active minimal/always/never/manual quote policy, detected source quote-preservation map, explicit header/body/column quote rules, and explicit per-cell quote/no-quote overrides. Save can apply quote character/mode settings, preserve sampled irregular quote decisions, toggle an active cell's manual quote state, bulk-apply quote/no-quote/clear overrides to selected cells, apply Settings-level row/column quote rules, and import/export quote-rule JSON, but full-file quote maps, richer rule editing UI, and escape-rule controls are still missing.
- File format presets can be saved, imported/exported as JSON, include header-column metadata, and be manually or automatically applied to the current local path through lightweight filename/path/content rules, and Settings can search/manage/reset presets and rules. Richer preset editing, explicit conflict ordering UI, and broader Settings categories are still missing.
- SQL WHERE row filter is implemented as a useful subset with documented functions plus date/time/timestamp/interval foundations, but bigint precision semantics, date/time arithmetic, full interval grammar, and every documented edge case are still incomplete.
- SQL console now uses SQLite for the core execution path and supports joins, subqueries, expression projection, `HAVING`, query history, URL-run bootstrapping, result CSV export, first-pass result range selection/copy, and a first result-cell context menu. Remaining gaps are streaming/virtual-table loading for very large files, richer error locations, encrypted temp-db mode if disk-backed temp storage is introduced, and richer result-grid actions beyond copy/export basics.
- Diff engine/API/CLI payload and a basic visual Diff View exist, with ignore options, header-name alignment, row alignment by key column, inline character spans, next/previous diff navigation, bidirectional merge actions for two files, a right-side pasted text mode, and a clipboard-load UI with fallback messaging. Browser-level system clipboard verification remains blocked by the current Browser runtime; richer conflict prompts and a fully virtualized side-by-side editor remain incomplete.
- Profile/validation exists as a useful foundation, but CSVLint-compatible rule sets, saved schemas, quick fixes, and incremental profiling for very large files remain incomplete.
- Command Palette is implemented as a first-pass command runner with fuzzy scoring, recent command history, and locally persisted shortcut customization/presets/import/export plus recording-time conflict replacement, but full action coverage remains incomplete.
- Theme support now covers light, dark, high contrast, system-following mode, the main app shell, and Canvas grid, and Settings has first-pass format-manager plus theme/grid/text font controls. Per-OS native title/menu integration, update/settings categories, richer editor appearance options, and design-token audit across every future surface remain incomplete.
- Full CLI/URL parity is not implemented yet: root CLI parsing/opening exists, but native desktop launch, wait-for-close, protocol handler registration, and actual diff view wiring remain.
- CLI/URL parsing exists as a reusable package, but it is not wired into a desktop protocol handler yet.
- Read-only and external file refresh foundations exist in local app mode, including active filter/sort preservation on clean refresh and a first conflict panel for dirty documents, but OS-level file watching and richer merge/compare conflict prompts are still missing.
- Transpose is implemented as a whole-document materialized operation with a cell-count guard, plus a rectangular selection transpose foundation for targets that fit in the current grid; large-file streaming transpose, target expansion, multi-range transpose, and a richer confirmation UI are still missing.
- Text transforms currently accept explicit selected cells with a frontend safety cap and include common naming/case and full-width/half-width conversions; streaming whole-column transforms, Unicode normalization variants beyond width mapping, custom separator UI, and richer split conflict handling are still missing.
- Native desktop shell is not implemented yet. Browser prototype now has a local start/recent foundation, but desktop-backed settings, recent storage, split editor groups from the v3.21.0 release, tab drag/drop between groups, and window geometry persistence remain incomplete.
- Browser verification is currently a mix of DOM/API checks and targeted screenshots for visual regressions.
